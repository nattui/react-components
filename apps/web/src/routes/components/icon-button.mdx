# Icon button

Icon buttons are controls that let users take action, make choices, and move forward.

```jsx
// component

<IconButton icon={<IconPlusOutline18 />} />
```

```jsx
<IconButton icon={<IconPlusOutline18 />} />
```

## Variants

The `IconButton` comes with three variants: `primary` (default), `secondary`, and `ghost`.

```jsx
// component

<IconButton icon={<IconPlusOutline18 />} variant="primary" />
<IconButton icon={<IconPlusOutline18 />} variant="secondary" />
<IconButton icon={<IconPlusOutline18 />} variant="ghost" />
```

```jsx
<IconButton icon={<IconPlusOutline18 />} variant="primary" />
<IconButton icon={<IconPlusOutline18 />} variant="secondary" />
<IconButton icon={<IconPlusOutline18 />} variant="ghost" />
```

## Size

The `IconButton` comes with 5 sizes: `32`, `36`, `40` (default), `44`, and `48`.

```jsx

<IconButton icon={<IconPlusOutline18 />} size={40} />
```

## Disabled

Use the `disabled` prop to prevent a button from being interacted with. Disabled buttons communicate that an action is currently unavailable.

```jsx
// component

<IconButton disabled icon={<IconPlusOutline18 />} variant="primary" />
<IconButton disabled icon={<IconPlusOutline18 />} variant="secondary" />
<IconButton disabled icon={<IconPlusOutline18 />} variant="ghost" />
```

```jsx
<IconButton disabled icon={<IconPlusOutline18 />} variant="primary" />
<IconButton disabled icon={<IconPlusOutline18 />} variant="secondary" />
<IconButton disabled icon={<IconPlusOutline18 />} variant="ghost" />
```

## Loading

Use the `loading` prop to indicate that an action is in progress. While loading, the button shows a spinner and cannot be interacted with.

Do not add `disabled` when using `loading`, as the button is automatically non-interactive while loading.

```jsx
// component

<IconButton icon={<IconPlusOutline18 />} loading variant="primary" />
<IconButton icon={<IconPlusOutline18 />} loading variant="secondary" />
<IconButton icon={<IconPlusOutline18 />} loading variant="ghost" />
```

```jsx
<IconButton icon={<IconPlusOutline18 />} loading variant="primary" />
<IconButton icon={<IconPlusOutline18 />} loading variant="secondary" />
<IconButton icon={<IconPlusOutline18 />} loading variant="ghost" />
```
