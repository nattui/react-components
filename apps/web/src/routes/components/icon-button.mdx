# Icon button

Icon buttons are controls that let users take action, make choices, and move forward.

```jsx
// component

<IconButton>
  <IconPlusOutline18 />
</IconButton>
```

```jsx
<IconButton>
  <IconPlusOutline18 />
</IconButton>
```

## Variants

The `IconButton` comes with three variants: `primary` (default), `secondary`, and `ghost`.

```jsx
// component

<IconButton variant="primary">
  <IconPlusOutline18 />
</IconButton>
<IconButton variant="secondary">
  <IconPlusOutline18 />
</IconButton>
<IconButton variant="ghost">
  <IconPlusOutline18 />
</IconButton>
```

## Disabled

Use the `isDisabled` prop to prevent a button from being interacted with. Disabled buttons communicate that an action is currently unavailable.

```jsx
// component

<IconButton isDisabled variant="primary">
  <IconPlusOutline18 />
</IconButton>
<IconButton isDisabled variant="secondary">
  <IconPlusOutline18 />
</IconButton>
<IconButton isDisabled variant="ghost">
  <IconPlusOutline18 />
</IconButton>
```

```jsx

  <IconPlusOutline18 />
</IconButton>
<IconButton isDisabled variant="secondary">
  <IconPlusOutline18 />
</IconButton>
<IconButton isDisabled variant="ghost">
  <IconPlusOutline18 />
</IconButton>
```

## Loading

Use the `isLoading` prop to indicate that an action is in progress. While loading, the button shows a spinner and cannot be interacted with.

Do not add `isDisabled` when using `isLoading`, as the button is automatically non-interactive while loading.

```jsx
// component

<IconButton isLoading variant="primary">
  <IconPlusOutline18 />
</IconButton>
<IconButton isLoading variant="secondary">
  <IconPlusOutline18 />
</IconButton>
<IconButton isLoading variant="ghost">
  <IconPlusOutline18 />
</IconButton>
```

```jsx

</IconButton>
```
