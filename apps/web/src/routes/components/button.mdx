import { Button, ButtonLink, Row } from "@nattstack/ui"
import { IconPlusOutline18 } from "@nattstack/icons"

# Button

Buttons are controls that let users take action, make choices, and move forward.

```jsx
// component

<Button>Button</Button>
```

```jsx
<Button>Button</Button>
```

## Variants

The `Button` comes with three variants: `primary` (default), `secondary`, and `ghost`.

```jsx
// component

<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
```

```jsx
<Button variant="primary">Primary</Button>
<Button variant="secondary">Secondary</Button>
<Button variant="ghost">Ghost</Button>
```

## Size

The `Button` comes with 5 sizes: `32`, `36`, `40` (default), `44`, and `48`.

```jsx
// component

<Button size={32}>Button 32</Button>
<Button size={36}>Button 36</Button>
<Button size={40}>Button 40</Button>
<Button size={44}>Button 44</Button>
<Button size={48}>Button 48</Button>
```

```jsx
<Button size={32}>Button 32</Button>
<Button size={36}>Button 36</Button>
<Button size={40}>Button 40</Button>
<Button size={44}>Button 44</Button>
<Button size={48}>Button 48</Button>
```

## Icons

You can place icons **before** the label (`iconStart`), **after** the label (`iconEnd`), or use an icon as the button label when the action is clearly represented by the icon.

You don't need to explicitly set the icon size. Icons inherit the correct sizing from the Button component by default.

```jsx
// component

<Button iconEnd={<IconPlusOutline18 />} iconStart={<IconPlusOutline18 />}>
  {"Button"}
</Button>
```

```jsx
<Button iconEnd={<IconPlusOutline18 />} iconStart={<IconPlusOutline18 />}>
  Button
</Button>
```

## Disabled

Use the `isDisabled` prop to prevent a button from being interacted with. Disabled buttons communicate that an action is currently unavailable.

```jsx
// component

<Button isDisabled variant="primary">Disabled</Button>
<Button isDisabled variant="secondary">Disabled</Button>
<Button isDisabled variant="ghost">Disabled</Button>
```

```jsx
<Button isDisabled variant="primary">Disabled</Button>
<Button isDisabled variant="secondary">Disabled</Button>
<Button isDisabled variant="ghost">Disabled</Button>
```

## Loading

Use the `isLoading` prop to indicate that an action is in progress. While loading, the button shows a spinner and cannot be interacted with.

Do not add `isDisabled` when using `isLoading`, as the button is automatically non-interactive while loading.

```jsx
// component

<Button isLoading variant="primary">Loading</Button>
<Button isLoading variant="secondary">Loading</Button>
<Button isLoading variant="ghost">Loading</Button>
```

```jsx
<Button isLoading variant="primary">Loading</Button>
<Button isLoading variant="secondary">Loading</Button>
<Button isLoading variant="ghost">Loading</Button>
```

## Full width

Use the `isFullWidth` prop to make the button expand to the full width of its container.

```jsx
// component

<Button isFullWidth>Full width</Button>
```

```jsx
<Button isFullWidth>Full width</Button>
```

## Rounded

Use the `isRounded` prop to give the button fully rounded corners.

```jsx
// component

<Button isRounded variant="primary">Rounded</Button>
<Button isRounded variant="secondary">Rounded</Button>
<Button isRounded variant="ghost">Rounded</Button>
```

```jsx
<Button isRounded variant="primary">Rounded</Button>
<Button isRounded variant="secondary">Rounded</Button>
<Button isRounded variant="ghost">Rounded</Button>
```

## Button Link

Use the `ButtonLink` component to create a link that looks like a button.

```jsx
// component

<ButtonLink href="https://www.example.com" rel="noopener noreferrer" target="_blank">
  {"Button Link"}
</ButtonLink>
```

```jsx
<ButtonLink href="https://www.example.com" rel="noopener noreferrer" target="_blank">
  Button Link
</ButtonLink>
```
