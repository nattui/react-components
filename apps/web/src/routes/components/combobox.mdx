# Combobox

Comboboxes let users choose an option from a list they can filter by typing into an input.

The `Combobox` component is a Base UI component.

Pass the options to the `items` prop on `Combobox` and render each one with a `ComboboxList` render function, so the list is filtered as the user types. `ComboboxEmpty` renders its children when no options match.

```jsx
// component

<Combobox items={FONTS}>
  <ComboboxInput className="max-w-256" placeholder="Search fonts" />
  <ComboboxContent>
    <ComboboxEmpty>No fonts found.</ComboboxEmpty>
    <ComboboxList>
      {(font) => (
        <ComboboxItem key={font} value={font}>
          {font}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

```jsx
const FONTS = ["Sans-serif", "Serif", "Monospace", "Cursive", "Fantasy", "System UI"]

return (
  <Combobox items={FONTS}>
    <ComboboxInput className="max-w-256" placeholder="Search fonts" />
    <ComboboxContent>
      <ComboboxEmpty>No fonts found.</ComboboxEmpty>
      <ComboboxList>
        {(font) => (
          <ComboboxItem key={font} value={font}>
            {font}
          </ComboboxItem>
        )}
      </ComboboxList>
    </ComboboxContent>
  </Combobox>
)
```

## Groups

Use `ComboboxGroup` with a `ComboboxGroupLabel` to label related options. Represent the options as an array of group objects with an `items` property, pass each group's `items` to its `ComboboxGroup`, and render the options with `ComboboxCollection` so filtering keeps working. Groups without a matching option are hidden.

```jsx
// component

<Combobox items={FONT_GROUPS}>
  <ComboboxInput className="max-w-256" placeholder="Search fonts" />
  <ComboboxContent>
    <ComboboxEmpty>No fonts found.</ComboboxEmpty>
    <ComboboxList>
      {(group) => (
        <ComboboxGroup items={group.items} key={group.value}>
          <ComboboxGroupLabel>{group.value}</ComboboxGroupLabel>
          <ComboboxCollection>
            {(font) => (
              <ComboboxItem key={font} value={font}>
                {font}
              </ComboboxItem>
            )}
          </ComboboxCollection>
        </ComboboxGroup>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

```jsx
const FONT_GROUPS = [
  {
    items: ["Sans-serif", "Serif"],
    value: "Proportional",
  },
  {
    items: ["Monospace"],
    value: "Fixed width",
  },
]

return (
  <Combobox items={FONT_GROUPS}>
    <ComboboxInput className="max-w-256" placeholder="Search fonts" />
    <ComboboxContent>
      <ComboboxEmpty>No fonts found.</ComboboxEmpty>
      <ComboboxList>
        {(group) => (
          <ComboboxGroup items={group.items} key={group.value}>
            <ComboboxGroupLabel>{group.value}</ComboboxGroupLabel>
            <ComboboxCollection>
              {(font) => (
                <ComboboxItem key={font} value={font}>
                  {font}
                </ComboboxItem>
              )}
            </ComboboxCollection>
          </ComboboxGroup>
        )}
      </ComboboxList>
    </ComboboxContent>
  </Combobox>
)
```

## Icons

Options can include an icon before their label and a supporting description. Use option objects shaped as `{ value, label, ... }`: the `label` is automatically used for the input text and for filtering, and the `value` for form submission.

```jsx
// component

<Combobox items={MODELS}>
  <ComboboxInput className="max-w-288" placeholder="Search models" />
  <ComboboxContent>
    <ComboboxEmpty>No models found.</ComboboxEmpty>
    <ComboboxList>
      {(model) => (
        <ComboboxItem key={model.value} value={model}>
          <Row className="items-center">
            {model.icon && <model.icon className="mr-8" size={18} />}
            <span className="truncate">{model.label}</span>
            {model.description && (
              <span className="text-13 text-gray-9 font-400 ml-6 truncate">
                {model.description}
              </span>
            )}
          </Row>
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>
```

## Disabled

Use the `isDisabled` prop on `ComboboxItem` to prevent a single option from being selected, or the `disabled` prop on `Combobox` to disable the entire control.

```jsx
// component

<Combobox items={FONTS}>
  <ComboboxInput className="max-w-256" placeholder="Search fonts" />
  <ComboboxContent>
    <ComboboxEmpty>No fonts found.</ComboboxEmpty>
    <ComboboxList>
      {(font) => (
        <ComboboxItem isDisabled={font === "Cursive"} key={font} value={font}>
          {font}
        </ComboboxItem>
      )}
    </ComboboxList>
  </ComboboxContent>
</Combobox>

<Combobox defaultValue="Sans-serif" disabled items={FONTS}>
  <ComboboxInput className="max-w-256" placeholder="Search fonts" />
</Combobox>
```

## State

By default, `Combobox` is an uncontrolled component that manages its own state. Use the `defaultValue` prop to set the initially selected option.

```jsx
<Combobox defaultValue="Sans-serif" items={FONTS}>
  <ComboboxInput placeholder="Search fonts" />
  <ComboboxContent>{/* ... */}</ComboboxContent>
</Combobox>
```

Use `value` and `onValueChange` props if you need to access or control the selected option. The text shown in the input can be controlled separately with the `inputValue` and `onInputValueChange` props.

```jsx
const [font, setFont] = useState(null)

return (
  <Combobox items={FONTS} onValueChange={setFont} value={font}>
    <ComboboxInput placeholder="Search fonts" />
    <ComboboxContent>{/* ... */}</ComboboxContent>
  </Combobox>
)
```
