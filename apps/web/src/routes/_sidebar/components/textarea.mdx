import { Column, Label, Spacer, Textarea } from "@nattstack/ui"

# Textarea

Textareas are form controls that let users enter and edit multi-line text.

```jsx
// component

<Column className="w-full max-w-480">
  <Label htmlFor="message">Message</Label>
  <Spacer height={4} />
  <Textarea id="message" placeholder="Share what's on your mind" />
</Column>
```

```jsx
<Textarea placeholder="Share what's on your mind" />
```
